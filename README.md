# Bill Splitter 🇳🇬

A mobile-friendly bill splitting app built with plain HTML, CSS and JavaScript.

**Live app:** (paste your GitHub Pages link here)

## Features
- Split equally or by what each person ordered
- Service charge, VAT and delivery, shared equally or by order amount
- Exact kobo rounding, so the shares always add up to the total
- Who paid and settle-up
- WhatsApp-ready summary (copy or share)
- Nigerian presets: Restaurant, Shared Bolt, Compound light bill
- Auto-saves your last bill in the browser

## Run it locally
Download the files and open `index.html` in a browser.
